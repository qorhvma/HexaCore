# 문제 해결

## 서보 두 개가 같이 움직인다

두 PCA9685의 I2C 주소가 같습니다. I2C 스캔에도 하나로만 보입니다. 보드의 A0~A5 점퍼를 바꿔 하나는 0x40, 하나는 0x41로 맞추세요.

## ESP32가 부팅되지 않는다

GPIO 5(다리 4 발 스위치)는 부팅 스트래핑 핀입니다. 켤 때 발이 바닥에 눌려 있으면 부팅 모드가 바뀔 수 있습니다. 다리를 띄우고 켜세요.

## IMU가 안 잡힌다

- BNO08x 주소는 보드마다 다릅니다(Adafruit 0x4A, SparkFun 0x4B). 펌웨어는 둘 다 시도합니다.
- BNO08x는 400 kHz에서 클럭 스트레칭 때문에 안 잡히는 경우가 있어 펌웨어가 100 kHz를 씁니다. 배선이 길면 더 짧게 해 보세요.
- IMU는 서보 드라이버와 다른 버스(SDA 32 / SCL 33)에 연결해야 합니다.

## 발 스위치가 어느 핀인지 모르겠다

펌웨어에 시리얼로 `p`를 보내면 핀 스캔이 켜집니다. 스위치를 누르면 `[핀] GPIO 17: 1→0`처럼 어느 핀이 바뀌었는지 나옵니다.

## 서보 하나가 기준 자세에서 안 움직인다

펌웨어가 켜질 때 출력하는 틱 표에서 그 값에 `★`가 붙어 있으면 서보 한계(약 600~2400 µs)에 걸린 것입니다. [서보 보정](../build/calibration.md)에서 `tCal`과 `JOINT_OFS`를 다시 맞추세요.

## 라즈베리파이가 ESP32를 못 찾는다

기본 포트는 `/dev/ttyUSB0`입니다. 다르면 `--port`나 환경변수 `HEXAPOD_SERIAL`로 지정하세요. 장치가 없으면 프로그램이 자동으로 시뮬레이션으로 바뀌니, 로그에서 시뮬레이션 여부를 확인하세요.
